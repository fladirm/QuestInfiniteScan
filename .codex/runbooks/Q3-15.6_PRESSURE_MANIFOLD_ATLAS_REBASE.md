# Q3-15.6 — PressureManifold Atlas Rebase

This run is the binding execution order for the audit of commit `3521c44`.
It is an architectural replacement of the rectangle-edge topology, not another
repair layer. `specka.md` (`CPQ3-2026-08-21-v6`) wins on conflict.

## Preserve

- four-stream finite-cone capture and first-hit/UNKNOWN semantics;
- one-sided competing ContactFilm hypotheses;
- quadratic/displacement posterior and monotonic information resistance;
- typed ABIs, generation-safe reusable storage, compact dirty lists;
- transactional count/validate/commit publication, indirect culling/rendering;
- versioned persistence framework and Quest shell.

## Remove as canonical behavior

- four `[0,1]^2` frontier edges per chart and `4 * film` frontier capacity;
- rectangle-edge validation/linking and unsupported rectangle materialization;
- root-index representative origin/frame/posterior publication;
- fixed two DSU waves or fixed parent-walk limits;
- transitive pairwise union without component representability/refit;
- fixed four-quadrant canonical split;
- FilmA-only boundary ownership or proximity-labelled multiview links;
- chunk transitions creating a manifold/seed/latent cut;
- repeated boundary spline search in mesh materialization;
- motion/time as the primary keyframe policy;
- unfenced GPU resource destruction.

## Implementation order

1. Define a shared atlas ABI: component, membership, support contour point/arc,
   oriented half-edge, FrontierLoop, shared BoundaryCurve incidence,
   ContinuationEvidence, cross-chunk portal, dirty-island and macrochart records.
2. Allocate segmented/reusable pools by measured contour complexity. Rectangle
   extents remain only chart numerical domains.
3. Replace spawn reduction with deterministic hook/shortcut convergence, global
   weighted component frame, exact candidate statistic rebase, aggregate robust
   refit and representability partition before transactional publication.
4. Extract contours from continuous Grid16/microtile support using deterministic
   marching squares, clip against shared persistent boundaries, weld/cancel proven
   compatible arcs and order remaining arcs into component FrontierLoops.
5. Commit smooth/crease/occlusion twins only from explicit evidence containing
   geometry covariance, sidedness, first-hit order, visibility, independent view
   bins and pose/calibration quality.
6. Make one shared BoundaryCurve own both incident half-edges and precompute its
   Grid16/microtile intersection cache when dirty.
7. Replace quadtree-only canonical split with evidence-aligned 2-4 partitions.
   Retain quadtree pages only for displacement/texture residency.
8. Compact dirty connected islands and run a bounded GPU elastic solve: smooth
   position+normal, crease position+hinge, no cross-discontinuity smoothing.
9. Keep lossless measured leaves; build derived macrocharts/meshlets for coarse
   prediction/LOD. Latent topology has FilmID zero and no prediction/export path.
10. Keep global component/half-edge identity across chunk ownership using ghost
    portals. Staging/eviction must not alter physical topology.
11. Separate contact-normal covariance terms from cone footprint bandwidth, add
    boundary-safe multiscale normals, GPU information-gain keyframes and fenced
    retirement for every live GPU resource class.
12. Update schema, restore/stage/materialization, code graph and product docs.

- nonrectangular support yields its measured contour and adjacent internal arcs cancel;
