## Non-negotiable repair order

Do not tune sigma, merge angle, preview alpha, aperture, or publication cadence

### A. Semantic ABI isolation and prediction feedback

Implementation surface:

```text
Runtime/Prism/Geometry/ContactFilmPool.cs
Runtime/Prism/Geometry/ContactMeshletBuffers.cs
Runtime/Resources/Prism/MeshletBuild.compute
Runtime/Resources/Prism/PredictContactFilm.shader
Runtime/Resources/Prism/ContactFilmPreview.shader
Runtime/Resources/Prism/MeshletViewCull.compute
Tests/Editor/PrismMeshletContractTests.cs
Tests/Editor/PrismTopologyContractTests.cs
```

Required design:

```c
ContactFilmFlags              // canonical film lifecycle only
ContactMeshletVertexFlags     // MeasuredContact, Boundary, LatentConnector, LatentFrontier
ContactMeshletDescriptorFlags // MeasuredSurface, HasBoundary, ElasticConnector, LatentFrontier
ContactMeshletViewFlags       // Visible, Occluded, FrustumRejected, Overflow
```

- Never assign `vertex.flags = film.flags` or `descriptor.flags = film.flags`.
- Ordinary contact vertices get explicit `MeasuredContact`, a non-zero FilmID, and
  the exact film generation.
- Latent connector/frontier vertices and descriptors get explicit latent flags and
  FilmID/generation zero.
- Prediction uses a positive eligibility predicate: valid FilmID/generation and
  `MeasuredContact`. It does not infer eligibility from a magic negative bit.
- Spawn, split, merge, snapshot restore, and revisit must all produce the same
  measured-vertex semantics.

Phase acceptance:

```text
new measured film -> next published prediction has >0 pixels for its ID/generation
latent connector/frontier -> prediction pixel count == 0
film flag values cannot change vertex/descriptor interpretation
split and merge retain identical prediction eligibility
```

### B. Canonical PressureManifold GPU pools and durable ABI

Add one explicit owner, provisionally:

```text
Runtime/Prism/Geometry/PressureManifoldPool.cs
Runtime/Resources/Prism/PressureManifoldTopology.compute
```

It owns bounded generation-tagged buffers for:

```text
PressureManifoldHeaderGpu
FilmMembershipGpu
ManifoldLinkGpu
LatentFrontierSegmentGpu
allocators + validation/counter state
```

The header owns manifold ID/generation, chunk, optical seed, membership/link/frontier
ranges and revision. Membership maps film ID/generation to manifold ID/generation;
split-lineage scratch must not double as membership. Links have typed classes
`Smooth`, `Crease`, `OcclusionFold`, and `Latent`. Frontier segments form ordered
generation-safe loops.

Wire the pool through work-graph lifetime, chunk staging, snapshot restore and a new
native PRISM schema revision. Older schemas widen to explicit latent/unlinked state;
they are never reinterpreted by current struct size.

Phase acceptance:

```text
active measured film -> exactly one live membership
membership generation mismatch -> fails closed
one connected scan session -> one optical-seed manifold unless explicit relocalization splits it
no active link endpoint references a retired/reused generation
restart restores identical membership/link/frontier graph
```

### D. Separate measured contact from latent conserved sheet

Coverage remains continuous information and never deletes canonical topology. It also
must not turn a full chart bounding rectangle into measured contact.

The mesh builder classifies derived cells as measured, mixed, or latent. Mixed cells
are contoured/partitioned at the continuous support boundary so measured triangles
carry explicit measured IDs while their welded latent continuation carries FilmID
zero. Do not rely on interpolated per-vertex IDs or provoking-vertex behaviour.

Rules:

```text
measured support -> predictor + normal preview/export material
latent sheet      -> topology/diagnostic material only, FilmID 0, no prediction, no normal GLB
coverage          -> confidence/refinement/material boundary, never topology deletion
```

Phase acceptance:

```text
front-only plate -> front predicts; back/closure remains latent UNKNOWN
two coplanar supports with a gap -> no measured triangles in the gap
unsupportedMeasuredTriangles == 0
latentPredictionPixels == 0
```

### E. Typed canonical links, safe merge, and symmetric topology transfer

`ContactBoundary` and `ManifoldLink` are different canonical entities. Replace the
current `FindAdjacentFilm -> ElasticManifoldLink` promotion with:

```text
screen adjacency -> LinkCandidate/occlusion evidence only
world-space coincident boundary + sidedness + first-hit order + multi-view continuation
                 -> typed canonical ManifoldLink
```

Until a link is proven, do not emit a connector. Foreground/background screen
neighbours never link across air.

Merge is allowed only through an explicit `Smooth` link or demonstrable overlapping
measured-support continuation. Prefer keeping two linked charts and renderer welding
over inventing support. If a larger chart is created, transform the exact support
field; its bounding parameter domain does not become measured material.

Split and merge process incident topology for both endpoint roles. Both films'
boundary/link incidence counts are maintained. Endpoint remap consumes split/merge
records, writes new generations atomically, removes duplicate internal links, and
fails closed if either endpoint is unresolved.

Before an inactive mesh generation may publish, GPU validation requires every active
chart edge to be exactly one of:

```text
SmoothLink | CreaseLink | OcclusionFold | ordered OuterLatentFrontier
```

`unpairedActiveEdges` or stale endpoints reject that publication; they do not cause
an invented curtain or per-film cap.

### F. Covariance-consistent pressure posterior and view decorrelation

After A-E pass depth-only fixtures, replace relative-best H/g weighting with a
globally defined physical precision unit. For accepted contact:

```text
pi = bounded 1 / (depth + pose + calibration + footprint + model covariance)
w  = confidence * robustInfluence * pi / fixedPrecisionUnit
H += saturatedIndependentContribution(w * J^T J)
g += saturatedIndependentContribution(w * J^T e)
```

The fixed unit preserves covariance meaning while keeping the integer-atomic range
bounded. It must not depend on the film's current best observation. Keep best
precision/footprint as a monotonic quality envelope, separate from accumulated H.

Add positive-contact independent view bins using eye, quantized chart-relative view
direction and meaningful baseline/time separation. Repeated near-identical frames
may add bounded support but cannot add unlimited H. Compute normal uncertainty from
the relevant posterior covariance (`H^-1`) plus learned depth/pose/calibration/model
floors; do not use only `rsqrt(bestPressure)`.

Phase acceptance:

```text
same-pose repeated frames -> bounded information gain
new independent baseline -> information increases
view-order permutation -> same posterior within fixed-point tolerance
close precise bake then far/grazing -> mean and sigma remain inside posterior bound
far first then close precise -> posterior improves
```

### I. Dirty/reusable transactional publication and view rendering

Canonical film storage uses generation-safe stable slots with a GPU free list. Retire,
split and merge return slots only after all published readers have crossed the
generation fence. Allocation first consumes reclaimed slots, then extends the bounded
high-water mark. No work domain is derived directly from that high-water mark.

Canonical mutations append a deduplicated dirty-active list. Mesh materialization is:

```text
compact dirty live films
-> exact count pass (measured contour + latent continuation + proven links/frontier)
-> prefix/range reservation
-> capacity/validation gate
-> emit into inactive generation
-> publish only if overflow==0 && staleEndpoints==0 && unpairedEdges==0
```

Any failure keeps the previous complete generation visible and predictive. Partial
atomic reservations never leak into a published generation.

Both prediction and headset preview consume GPU-compacted descriptor/index lists from
`MeshletViewCull`, with screen-space geometric-error LOD and conservative visibility.
The preview uses a front-depth prepass followed by a color pass (`ZTest Equal`, no
second depth write); latent diagnostic material is an explicit optional overlay, not
ordinary alpha-blended measured geometry.

Phase acceptance:

```text
allocator churn with bounded live films -> bounded slots and build work
one dirty film in a large resident world -> O(1) build dispatch domain
capacity overflow -> previous generation remains published bit-identically
preview visible set == view-cull output; no raw whole-world draw path
opaque/frontmost diagnostic -> no order-dependent alpha accumulation
```

### J. Exact boundary-constrained tessellation and symmetric incidence

Persistent boundaries partition chart cells in parameter space. The count/emit passes
clip/split every crossed cell against the canonical curve and emit matching boundary
vertices from one shared curve sample identity. FilmA and FilmB both own symmetric
generation-safe incidence and both snap/weld to the same samples. A boundary may be a
crease, occlusion fold, or outer latent frontier; it is never merely telemetry.

Screen-space adjacency remains observation evidence only. A typed `ManifoldLink` is
materialized only after world-space coincidence, first-hit ordering, sidedness and
multi-view continuation prove it. Link transfer remaps either endpoint through every
split/merge record before validation/publication.

Phase acceptance:

```text
boundary crossing cell -> no triangle crosses the supported discontinuity
FilmA/FilmB -> identical shared boundary positions and generations
split either endpoint -> all incident edges remap or publication fails closed
pole/background image adjacency -> zero physical connector triangles
```
