# S4-08.3D — transition/residency closure

Date: 2026-08-23
Authority: `new_spec.md` (`CPQ4-2026-08-22-S16-v6`)
Device evidence: S4-08.3C run archived under `.device-forensics/`

This is one surgical closure of the existing streaming graph. It adds no physical
object, topology graph, second world, CPU scheduler, heuristic acceptance or new
evidence subsystem.

## Frozen invariants

- `Psi : Sigma_2 -> S16` is the only canonical physical state.
- Absence of evidence is not evidence for physical `z_null`.
- Page/block/bundle boundaries and Morton allocation addresses have no physical or
  identity meaning.
- Endpoint topology claims require their own exact evidence. Contact-side stereo
  provenance cannot prove an unobserved null endpoint.
- Dormancy retains complete minimal proof plus only unresolved raw residue. Scratch
  or scheduling capacity never truncates evidence.
- Canonical output, proof, validity and provenance are invariant under page layout,
  bundle partitioning, token budget and interleaving.
- GPU owns association, inverse, proof, transition and publication. Diagnostics are
  observational only and may not control work or mutation.
- Every touched shader is read in full with its ABI/binds and emitted as one
  coherent complete-file replacement.

## D1 — evidence-qualified transition endpoint

Use one endpoint resolver and the existing state/status/provenance records. Its
ephemeral result is exactly one of:

```text
WITNESSED_CONTACT
WITNESSED_NULL_PASS_THROUGH
UNOBSERVED
CONFLICT
```

- Candidate/current supported state with exact inclusive evidence is witnessed
  contact.
- Physical null is witnessed only by the null side's own independent exact
  pass-through/exclusion evidence. OR-ing the contact endpoint's eye bits cannot
  establish it.
- A missing, unallocated or not-yet-visible neighbour is unobserved. Keep the
  `z_null` value as a numerical sentinel, but emit no tau, discontinuity,
  annihilator or associator topology claim for that edge.
- Conflict stays unresolved and cannot publish.
- Resolve an exact candidate neighbour from the same atomic publication set before
  manifest-visible `Psi`; otherwise return unobserved, never physical null.
- Never consume an unrelated uncommitted shadow page. Dependency/ticket order and
  publication generation remain semantic authority.

## D2 — stable probation association

- `StreamGaugeOrdinalBase` remains deterministic address allocation only.
- Existing prediction remains a disposable proposal. A dormant candidate may also
  propose its retained candidate/proof anchor through the existing revalidation
  association path.
- Exact Q16.48 admissible-cell/first-hit viability decides whether new sealed
  evidence joins that probation. A wrong proposal fails closed and allocates a new
  gauge; no XYZ/image proximity identity or FP canonical decision is introduced.
- Probation remains noncanonical and never enters ordinary prediction, publication
  or readout before its exact promotion proof closes.

## D3 — transfer dormant evidence, then reclaim execution residency

Reuse `SigmaConstraintLedger`; do not add a durable source-log/pool.

```text
ACTIVE bundle: full transient 64-block payload
  -> inverse + minimal proof closure
  -> unresolved transition
  -> proof certificates + required raw residue
  -> ledger-owned raw chain / immutable frame provenance
  -> dormant probation anchor
  -> reclaim bundle/calibration/execution slot
```

- The retained raw mask is the union of existing proof raw-required blocks and the
  blocks implicated by the unresolved transition. `counts.w` alone is insufficient.
- Transfer payload before releasing its bundle. If a ledger raw reservation cannot
  be proven, remain `PARK_PENDING`; never free, truncate or publish.
- Use existing raw headers/words/frame records/live bitmap and generation-safe
  handles. A reused bundle slot may not overwrite retained raw or frame provenance.
- Calibration replay must be bit-identical. Reconstructing exact calibration from
  retained frame provenance is legal only behind an exact fixture; otherwise retain
  the existing exact calibration bytes with the evidence anchor.
- Dormant stores the existing proof/evidence handles and dependency fingerprint,
  not copied geometry or another canonical state.

## D4 — ingress ownership

- Advance ingress cursor only after the candidate's immutable payload is GPU-owned.
- Resident exhaustion is backlog/backpressure, never silent skip/drop. Releasing a
  transient capture lease without first sealing ownership is not retention.
- S4-10 supplies durable long-session paging/spill. This run removes the proven
  finite-window deadlock and never claims losslessness beyond actually owned data.

## D5 — diagnostics and fail-closed publication

Extend only the existing asynchronous diagnostic packet with:

```text
implicitNoClaim, explicitNull, crossPageDeferred,
rawTransferred, bundleReclaimed, parkPending, ingressNotOwned
```

No new readback request is allowed. Publication continues to require accepted exact
evidence, closed proof and closed claimed transitions. An unobserved edge neither
fails nor proves topology; an explicit unresolved edge remains dormant.
