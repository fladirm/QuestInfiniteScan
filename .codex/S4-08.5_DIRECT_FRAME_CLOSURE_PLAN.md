# S4-08.5 direct-frame closure repair

Baseline: `d3b83e1c47abfffe33ec759875a8b6545b78435b`.
Canonical specification remains `CPQ4-2026-08-24-S16-v7`; ADR-S413 and the
S4-08.4 direct-frame ontology remain valid. This run completes that implementation;
it does not introduce another reconstruction graph, world or fallback.

## 1. Device-forced reopen

The installed baseline reaches coherent 320x320 capture, constructs a 14-slot
2048-MiB frame arena, then fails before the first inverse dispatch with:

```text
Sigma direct-frame submission failed:
Direct-frame execution window is incomplete or segmented.
```

`SigmaFrameGraph.RequireSingleExecutionWindow/Single` rejects legal segmented
buffers. `SigmaInverseController` then latches `_completionFaulted`, stops future
submissions and releases ingress. Capture continues, but revision/readout/topology
remain zero. This is the immediate empty-scan root cause.

The source audit also proves the graph cannot be accepted after merely removing
that throw. All gaps below are one incomplete direct-frame dataflow contract.

## 2. Frozen invariants

- The only canonical world is `Psi : Sigma_2 -> S16` in exact checked Q16.48.
- One coherent D_L/D_R/RGB_L/R frame is one owned observation and one sparse
  revision boundary. It is never partially admitted.
- Execution windows, pixels, pages, segments and workgroups have no physical or
  identity authority.
- Prediction/current, pending, continuation and novel are proposals only. The same
  exact four-source meet and first-hit rules decide all of them.
- Every source targeting one carrier sample participates losslessly in one exact
  reduction before a final state is built. Dispatch order cannot select a writer.
- Pending and intrinsic edge closure use complete S16 state and generated exact
  transition algebra; XYZ/image proximity never accepts identity.
- UNOBSERVED makes no null claim. An unresolved claimed edge defers only incident
  changed mutations to a fixed point.
- A revision becomes visible only after final state, evidence, transition witnesses
  and every shadow page are complete. Readers observe one root, never page flags as
  independent authority.
- Source journals remain owned until replaced by a generation-safe exact
  certificate or retained raw record. Scratch capacity is never a proof cap.
- Association/readout/profiling are disposable. CPU never reads pixels or chooses
  canonical work.
- No legacy streaming graph, transaction, token scheduler, Morton allocation,
  CPU fallback or alternate graph may return.

## 4. One replacement dataflow

```text
OWNED COHERENT FRAME
  -> aligned execution windows (complete logical streams)
  -> CURRENT / persistent PENDING / CONTINUATION / NOVEL proposals
  -> four exact source cells
  -> compatible target records
  -> stable target-key ordering
  -> exact source reduction + final state + retained certificate
  -> exact pending/dirty-edge closure and incident deferral to fixed point
  -> CHANGED canonical targets only
  -> segmented paired shadow allocation/scatter
  -> one generation-safe revision manifest/root
  -> prediction + temporary XR readout
```

There is no persistent per-window transaction. A window is only a binding-safe
slice recorded in fixed order inside the same command graph.

## 5. Deterministic implementation map

### A. Generated ABI and aligned windows

1. Keep the existing seven generated frame records. Normalize
   `SigmaFrameDeltaGpu` into the one complete target record/key and reduce it
   in-place through one ping-pong buffer. Reuse `SigmaPendingGaugeGpu`,
   `SigmaDirtyEdgeGpu`, existing ledger certificate/raw records and packed `uint4`
   carrier/revision handles. Add no parallel ABI family.
2. `SigmaFrameResources` chooses one footprint-window size from the smallest legal
   Vulkan binding range and aligns every per-footprint segmented buffer to it.
3. Every segment exposes `(firstFootprint,count,buffer)`; all kernels receive global
   first/count and use window-local storage indices. Delete
   `RequireSingleExecutionWindow` and `Single` from production recording.
4. Source, proposal, meet and compact passes iterate the same ordered windows.
   Cross-window results enter the one logical target-record stream; no observation
   is truncated or processed twice.

### B. Canonical target stream

5. Proposal address normalization emits one complete key inside the existing delta
   record. CURRENT masks the
   packed sample and carries eye/source identity only in provenance. Segment,
   page, sample, generation and logical coordinate remain intact.
6. Emit persistent pending candidates before continuation and novel. Pending
   records live in the existing frame-resource arena with generation/dependency
   handles; per-frame labels are scratch views, not ownership.
7. Stable compact accepted records, stable-sort by complete target key and source
   tie key, then reduce each equal range by exact max(lower)/min(upper), validity,
   gaps and lexicographic provenance.
8. `FinalizeFrameCandidates` alone constructs the minimum-change S16 state and
   width-derived mass from the complete reduced joint cell. Provisional per-source
   candidate states cannot reach publication.
9. Emit `UNCHANGED`, `CHANGED`, `CONFLICT`, `UNRESOLVED` and `FAULT` distinctly.
   Only CHANGED enters canonical scatter; no-change still records observation
   evidence without allocating a generation.

### C. Pending and transition closure

10. `BuildPendingEdges` only emits candidate edges from exact first-hit proposal
    relationships. `ClosePendingEdges` runs the existing generated S16
    regular/singular/no-claim rules before union.
11. Existing persistent pending gauges are exact proposal sources on later frames.
    A compatible continuation into a current carrier implicit-null neighbourhood
    is tested before independent novel promotion. No Morton/image/page identity.
12. After final target states, enumerate unique intrinsic edges incident to CHANGED
    samples. Resolve shadow endpoint, then base revision, then UNOBSERVED.
13. Run exact annihilator/associator/null gates for claimed edges. An unresolved
    claimed edge sets only its changed endpoint defer bits; rebuild incident edges
    until a GPU changed-count reaches zero. Deferred CURRENT uses prior state;
    deferred NOVEL remains pending with its evidence.

### D. Evidence, carrier and atomic publication

14. The reduced exact joint cell plus ordered provenance is the live certificate
    for a resolved target. Store it once in the existing constraint-ledger
    generation-safe pools; do not retain four full source arrays for that target.
15. Before releasing an owned frame, copy only unresolved/raw-required footprints
    once into the ledger raw store and attach refcounted handles. Allocation uses
    existing live/free metadata and segmented growth; no monotonic session cursor.
16. Replace the one `_gpuManagedSegment` target with all binding-safe carrier
    segments admitted by the memory profile. A GPU paired free list returns
    `(segment,page)` handles; retired shadow generations reclaim after completion.
17. Prepare/scatter is grouped by destination segment and preserves source segment
    identity. Revision manifest entries contain full segment/page/generation
    handles. One root becomes visible only after all groups and witnesses close.
18. Revision slots use generation-safe free/reclaim ownership, not `revision % 256`.
    Prediction, topology and XR readout resolve the same root manifest.
19. Remove or adapt CPU `_latest/_allocated` authority for direct GPU pages; there
    is exactly one current-generation truth. CPU may mirror published immutable
    handles for persistence/export but cannot independently decide current state.

### E. Lifecycle, diagnostics and truthful UI

20. A submitted frame completes as `published`, `no-change`, `retained-unresolved`
    or `faulted`; fence completion alone is not a committed frame.
21. If no frame window or evidence destination is available, the complete frame
    remains not-admitted/backpressured without pinning an unbounded prediction ring.
    Accepted frames are never dropped or partially owned.
22. Keep the existing per-kernel GPU markers. Add window/record/target/reduction/
    edge/page/journal counts and explicit timing-supported status to the existing
    diagnostic readback; telemetry never controls scheduling.
23. Temporary pre-S4-11 readout remains disposable and displays manifest-visible
    CHANGED support immediately. No preview fix may hide a canonical failure.

Shaders/includes are manually read with all call sites, then replaced as coherent

No fourth frame shader, manager, queue, compatibility branch or legacy fallback is
allowed. The reduced delta buffer is simultaneously the final-state input,
certificate source, dirty-edge source and scatter source. The same packed carrier
handle is used by prediction, reduction, publication and readout. Reuse generated
exact operators, stable scan, constraint ledger, carrier segments, completion
tickets and readout buffers already present.

## 8. Required regression oracles

1. 320x320 one/many legal binding windows -> identical full outputs.
2. Two and many footprints targeting one sample -> exact source-order-independent
   meet; no multiple writer.
3. Right-eye-only CURRENT -> correct sample and provenance.
4. Same page slot in two segments -> correct segment selected.
5. Repeated unmatched wall -> one pending gauge; side reveal tests continuation.
6. Thin/fold/parallel surfaces never join by image/XYZ proximity.
7. UNOBSERVED edge makes no claim; claimed unresolved defers incident changes only.
8. UNCHANGED frame allocates no page generation and publishes no false change.
9. Reused frame slot cannot invalidate any published witness.
10. Revision-slot wrap and carrier segment growth cannot alias live generations.
11. Page/window/workgroup/order changes preserve byte-identical Psi, validity,
    gaps, provenance, certificate and transition signatures.
12. Live bind helper Vulkan matrix catches one removed binding.
