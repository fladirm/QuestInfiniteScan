## 1. Frozen semantic equation

### 1.1 World

\[
\boxed{\Psi:\Sigma_2\rightarrow S16}
\]

`Σ₂` is one signed-64 intrinsic carrier/gauge. It is not an atlas of physical
chart objects. Supported and disconnected manifestations are values/relations of
the field.

### 1.2 Canonical default

The authoritative program must prove a canonical no-manifestation representative

\[
z_\varnothing\in S16.
\]

Only after sensor/eye/export no-manifestation proof and exact intrinsic-relation
parity between unbacked and allocated-default addresses may unbacked storage and
`NULL` codec blocks stand for this same value. A default/support boundary may have
defined native relation semantics. Current `ZNullDyad` plus `Gz=0` is not
sufficient evidence.

The generated code name is `ZEmpty`. Replacing supported state by `ZEmpty` is a
physical mutation and may reveal farther first-hit support. Only the following is
representation-transparent:

\[
\mathfrak M_q[\operatorname{Decode}_{unbacked}(\Psi)]
=
\mathfrak M_q[\operatorname{Decode}_{explicit\;z_\varnothing}(\Psi)].
\]

An all-default neighbourhood must yield reducer identity, `DEFAULT_SAT` and zero
active work for every generated arity. Mixed default/support boundaries retain
their descriptor-defined relation semantics.

### 1.3 One relation-program authority

\[
\boxed{
\mathfrak M=
\operatorname{Compile}(\mathcal A_{S16},I_{TOE},I_Q)
}.
\]

`𝔐` is one fingerprinted IR with query entry points, not one monolithic kernel.
Every specialized plan inherits its expressions, arity, brackets, coupling,
default semantics and reverse contractor from this IR.

`I_TOE` supplies authoritative native Merkaba/eigenmode law. `I_Q` supplies frozen
sensor/finite-footprint, eye, intrinsic-query, export and debug boundary schemas.
Every IR node records algebra/TOE/query provenance in the same bundle fingerprint.
Runtime pose/calibration only instantiates query parameters.

For any query:

\[
Y_q=\mathfrak M_q[\Psi].
\]

### 1.4 Scan

\[
Y_t=(O_L,O_R,\Gamma_t)
\]

is one coherent stereo observation. Depth and optical leaves per eye remain
separately retained, non-bootstrap and non-weighted until their reverse constraints
meet; their common footprint, pose, first-hit and occlusion context remains shared.

\[
\mathcal A_q(O)=\{\Phi:\mathfrak M_q[\Phi]\in O\}.
\]

Alternative preimages remain a mathematical union and transient contractor
scratch. They are never physical branch/chart/object identities.

### 1.5 One close/commit

\[
\boxed{
\operatorname{NativeCloseCommit}(\Psi_t,Y_t,\mathcal C_t)
}
\]

combines accumulated evidence, both sensor shadows and native relation predicates
before selection. It publishes only a uniquely resolved or complete-union-common
full-S16 delta.

If the current field remains feasible, canonical bytes remain unchanged.

Selector preservation is defined by equivalence fibres of the complete accumulated
Merkaba program. A kernel/right-lift optimization is legal only after a generated
complete-coupling proof.

### 1.6 Native directional action and locality information

The scene reducer yields the exact clear pre-hit sector, measured first-hit mould
and behind-hit `NO_CLAIM`. Reverse evaluation of that same bracketed sensor program
emits an exact query-direction action/cotangent witness. It is not a pressure
buffer, physical field, gradient solver or carving pass.

Each sampled locality retains an exact feasible-set/coupled-factor certificate.
A generated directional information form `H_xi` may compress that proof only with
an equivalence/reconstruction gate. It is not an S16 lane, scalar confidence or
second cell world. Compatible evidence intersects monotonically; incompatible
evidence preserves gaps/disjunction and is never averaged.

The two mechanisms are one closure: new directional action is the observation's
reverse constraint; accumulated locality information is the already-retained
constraint/resistance. Exact feasible-set intersection remains authoritative.
